# AI Junction Website

Static HTML/CSS/JavaScript marketing website. No build step required.

## Preview
Open `index.html` in a browser.

## Deploy
Upload all files to a GitHub repository. For Vercel choose Framework Preset **Other**, no build command, and output directory `.`. For Cloudflare use static assets hosting.

## Before launch
Replace the placeholder Facebook and YouTube links in all HTML files with your exact page/channel URLs. Replace placeholder article/tool links (`#`) with real content. Courses is Coming Soon.

Note: Vercel Hobby has non-commercial restrictions; use hosting terms appropriate to your marketing/business site.
